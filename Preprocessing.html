6. Fungsi Preprocessing Teks

Langkah-langkah dalam fungsi preprocessing():

  • Mengubah Tipe Data: Memastikan input bertipe string (teks).
  • Case Folding: Mengubah seluruh teks menjadi huruf kecil.
  • Hapus URL & Email: Menghilangkan tautan web dan email via regex.
  • Hapus Angka & Simbol: Membuang karakter angka, tanda baca, serta emotikon.
  • Hapus Spasi Berlebih: Merapikan spasi ganda.
  • Tokenisasi & Normalisasi: Memecah kata dan mencocokkan dengan kamus kata tidak baku & kata asing.
▶ 
def preprocessing(text):
    text = str(text)
    text = text.lower()

    # Hapus URL
    text = re.sub(r'https?://\S+|www\.\S+', ' ', text)

    # Hapus Email
    text = re.sub(r'\S+@\S+', ' ', text)

    # Hapus Angka
    text = re.sub(r'\d+', ' ', text)

    # Hapus Tanda Baca, Simbol, Emoticon
    text = re.sub(r'[^a-zA-ZÀ-ÿ\s]', ' ', text)

    # Hapus Spasi Berlebih
    text = re.sub(r'\s+', ' ', text).strip()

    # Tokenisasi
    kata = text.split()

    hasil = []
    for token in kata:
        # Normalisasi Baku & Asing
        if token in kamus_tidak_baku:
            token = kamus_tidak_baku[token]
        if token in kamus_asing:
            token = kamus_asing[token]

        hasil.append(token)

    return " ".join(hasil)
